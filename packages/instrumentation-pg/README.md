# @reqray/instrumentation-pg

pg driver instrumentation for Reqray.

Part of [Reqray](https://github.com/reqray/reqray) — a dev panel and request-inspection tool for
Node.js. It instruments HTTP, SQL, outgoing calls and cache on its own, shows
every request as a waterfall, and finds N+1 down to the file and the line.

Documentation, screenshots and a demo that runs with one command are in the
[main README](https://github.com/reqray/reqray#readme).
